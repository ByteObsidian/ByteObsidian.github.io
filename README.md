# ByteObsidian

A responsive, static cybersecurity portfolio for ByteObsidian, highlighting security tooling, attack-surface research, application security, and responsible testing. Upstream security projects are explicitly credited. The site has no build step or runtime dependencies.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Publish on GitHub Pages

1. Create a public repository named `ByteObsidian.github.io` under the `ByteObsidian` account.
2. Push these files to the repository's default branch.
3. In the repository settings, open **Pages** and select **Deploy from a branch**, the default branch, and the repository root.

GitHub Pages will publish the site at `https://byteobsidian.github.io/`.
